# 《署名》舞台影像系统

致知科学社 2026 社团风采展 · 五幕话剧《署名》（V1.4）的舞台大屏背景。

这是一套**本地运行的网页投影系统**，不是宣传网站。画面留给演员，操作留给后台；所有幕页预载在一个放映器里，切幕不刷新。

## 快速开始

推荐浏览器：**Microsoft Edge / Google Chrome**。建议投影仪使用电影/剧院模式，环境灯压暗；白纸场景的纸面亮度是视觉焦点，演员灯位请现场复核。

1. 将电脑连接到投影，设置为 **1920 × 1080**，显示缩放保持 100%。
2. 在后台电脑打开 `index.html`（播控台）。
3. 点击右上角 **「打开放映器」**，把弹出的 `stage.html` 拖到投影屏。
4. 放映器打开后会直接进入预演，屏幕上不出现操作按钮、键盘提示或时间码。
5. 在放映窗口的画面内点击一次（或按 `F`）进入全屏；随后切回播控台。
6. 在播控台点按场次、提示与黑场，也可以在放映窗口直接用键盘操作。
7. 开演前请完整走一遍：`1 → 5` 切幕，`Space` 推进 cue，`B` 黑场，`R` 重播，`F` 全屏。

需要临时调试时，可打开 `stage.html?setup=1` 进入旧版开始页；该页面仅供后台设置，**不要在观众面前使用**。若只想让舞台页自己显示一个很小的操作 HUD，可使用 `stage.html?hud=1`；正式演出不要加这个参数。

如果浏览器限制本地文件功能（个别 Chrome 安全设置会禁用跨窗口通信或弹窗），在项目根目录运行：

```bash
python3 -m http.server 8080 --directory htmlS
```

然后打开 `http://localhost:8080/`。用本地文件直接双击 `index.html` 也可以，已在 Edge 中验证。

## 键盘

| 键 | 动作 |
| --- | --- |
| `0` | 回到预演 / 开场画面 |
| `1` – `5` | 一键切到对应幕，自动从该幕 cue 1 开始 |
| `Space` / `→` / `PageDown` / `Enter` | 下一提示 |
| `←` / `PageUp` / `Backspace` | 上一提示 |
| `B` | 黑场 / 恢复 |
| `R` | 重播当前幕（回到 cue 1） |
| `F` | 进入 / 退出全屏 |

播控台与放映器在同一浏览器配置下通过 BroadcastChannel 或窗口消息连接。**一台电脑建议只开一个放映器窗口。** 全屏请直接在放映窗口点击画面或按 `F`；这是浏览器安全策略要求的真实用户手势，后台按钮不能替代。

## 场次与 Cue

| 场次 | 页面 | Cue 数 | 关键画面 |
| --- | --- | ---: | --- |
| 预演 | `scenes/preshow.html` | 1 | 片名、剧团、观演提示 |
| 第一幕 · 三十七页 | `scenes/act-1.html` | 5 | 论文、署名、未拆家书 |
| 第二幕 · 消息 | `scenes/act-2.html` | 5 | 收音机、塔斯社电波、暂停援助、家书 |
| 第三幕 · 一封签了名的信 | `scenes/act-3.html` | 5 | 联名信、决心书、1961 北京 |
| 第四幕 · 第九次 | `scenes/act-4.html` | 5 | 黑板、苏方数据、最大功、擦除 |
| 第五幕 · 署名 | `scenes/act-5.html` | 6 | 电话、号外、抽屉旧稿、谢幕 |

开演时的切换建议：

- 预演 → 第一幕：旁白“一九五七年春天……”起，按 `1`。
- 第一幕 → 第二幕：第一幕 cue 5 黑场后，按 `2`。
- 第二幕 → 第三幕：收音机与家书段结束、钱三强上场前，按 `3`。
- 第三幕 → 第四幕：屏幕出现 `1961 · 北京` 后，按 `4`。
- 第四幕 → 第五幕：黑板擦空、灯暗后，按 `5`。
- 第五幕：`Space` 依次经过报喜、号外、抽屉旧稿；“这个，用不上了”之后按到黑场，再按到谢幕并保持到掌声结束。

每一幕的 cue 名称与操作备注也在播控台右侧的 **CUE SHEET** 里，点击任意 cue 可以直接跳到该画面。

## 压缩构建

`js/` 下是 Google Closure Compiler（`SIMPLE_OPTIMIZATIONS`，已关闭 polyfill 注入）压缩后的脚本，未压缩源码保留在压缩之前的 git 提交里。改动脚本后可重新压缩：

```bash
bash tools/minify.sh
```

需要 Java 11+ 与 Node；脚本默认用 `npx google-closure-compiler` 调用编译器，也可以用 `CLOSURE_JAR=/path/to/compiler.jar` 指定本地 jar。压缩只影响 `js/`，HTML、CSS 与字体不动。

## 设计说明

- 视觉原则：**一盏灯照亮一页纸，纸上的人名正在消失。**
- 画面材质来自剧本：雪窗、论文、收音机、信纸、黑板、煤炉、黄昏办公室、旧报纸。
- 字幕只在剧本要求的位置出现；每幕设有独立的灯光、纸张、天气和道具运动。放映页面默认不显示操作界面，所有场次/提示/黑场信息在播控台。
- 动效只用 CSS 与原生 Canvas；无外部动画库、无网络依赖、无音频。
- 所有文字尽量使用本地字体子集；页面在 1366×768 与 1920×1080 下按 16:9 安全画幅缩放。
- 真实核爆照片未使用；罗布泊报喜只用光、波和纸面来表现。
- 第三幕联名信上的其他签名与姓名是舞台道具的视觉处理，不是历史人物真实签名；剧本所称“二十余人”中可考的具体名单未在本剧中使用。
- 页面采用舞台专用 16:9 固定构图，非通用宣传站；演员可与大屏同时出现，画面不设置常驻导航或鼠标交互。

## 验证

已在 1920×1080 与 1366×768 下实际运行并截取关键画面；验证过：

- 六页预载完成，自动进入预演，切幕不刷新；
- 播控台打开放映器、连接、一键切幕、上一/下一提示、重播、黑场；
- 快速连续切幕和 cue 跳转不会卡在黑场；
- 播放控制只出现在后台，默认投影页面无操作按钮、键盘提示或时间码；
- 单幕页可直接打开排练；
- 本地字体子集覆盖全站文案（未覆盖的数学/箭头符号由系统字体回退）。

**尚未在真实场地验证**：浏览器全屏授权（需要真实鼠标/键盘手势）、实际投影亮度下的白纸与暗部、演员站位对画面关键名字的遮挡。建议在走台时完成这三项。独立视觉评审给出 7/10，认为可演；剩余主要是材质统一和真实投影下的亮度/走位复核。

截图与评审过程保存在本任务目录的 `.oil-ui/shuming-stage/`，不随演出页面一起发布。
